# TempoAgentPay Demo Script

1. Open the dashboard home page and frame the product as a budget-safe paid-agent control plane.
2. Point out the topline cards: total tasks, success rate, total spent, average cost, latency, and fallback rate.
3. Use the recent task table to open a successful task and call out the ledger-backed detail view.
4. On the task detail page, show the fallback marker where ProviderA fails and ProviderB succeeds.
5. Open Provider Health and sort by success rate to show operational visibility by provider.
6. Open Policy Control, change max retries or kill-switch, save, and show the confirmation toast.
7. Open Task Runner, submit a new task, and show the immediate task ID plus live handoff into the detail page.
8. Close on the point that the UI is wired through adapter routes, so it can sit in front of the real AgentPay backend or mock payloads for local demo mode.
