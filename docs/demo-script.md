# Tempo Query Commerce Demo Script

1. Open the dashboard and frame the product as a pay-per-query knowledge base, not a generic agent console.
2. Call out the topline cards: paid queries, answer rate, revenue, revenue per query, latency, and citation coverage.
3. Show the recent paid queries table and open a receipt to prove each answer is monetized and auditable.
4. On the receipt page, walk through the grounded answer, citations, and Tempo-flavored settlement metadata.
5. Open Retrieval Health to show that the product also exposes operator-grade runtime visibility.
6. Open Pricing Policy, change the query ceiling or citation limit, save, and show the confirmation toast.
7. Open Ask KB, submit a new query against a source collection, and show the immediate charge preview plus receipt handoff.
8. Close on the point that the app can run locally for demo mode today and still preserve the proxy shape for a real backend later.
